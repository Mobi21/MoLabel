# MoLabel CLI Recipes

- Detect workspace: `molabel workspace detect`
- Check backend: `molabel doctor --json`
- Show command contract: `molabel manifest --json`
- List reviewer profiles: `molabel session list-reviewers --json`
- Add a second reviewer for an overlap queue: `molabel reviewer create --display-name "Reviewer 2" --json`, then act as it with `molabel session switch <reviewer-id> --json`
- List datasets: `molabel dataset list --json`
- Create a task schema from JSON: `molabel task-schema create --file schema.json --json`
- Create a prompt from JSON: `molabel prompt create --file prompt.json --json`
- Show templates: `molabel workflow templates --json`
- Create a workflow from a template: `molabel workflow create --template human_in_the_loop --dataset <dataset-id> --task-schema <task-schema-id> --json` (both default to the workspace's only dataset and task schema)
- Run a workflow: `molabel workflow run <selector> --json`
- Inspect executions: `molabel workflow execution <selector> <execution-id> --json`
- Claim review work: `molabel queue claim <queue-id> --json`
- End review on a queue with more copies than reviewers: `molabel queue close-copies <queue-id> --json`
- Submit a review: `molabel review submit <task-id> --labels-file labels.json --decision accept --json`
- List a queue's disagreements: `molabel adjudication list <queue-id> --json`
- Show one with every reviewer's labels: `molabel adjudication show <queue-id> <record-id> --json`
- Resolve it on the review events `show` printed: `molabel adjudication resolve <queue-id> <record-id> --review-event-ids <id>,<id> --resolved-labels-file labels.json --json`
- Create a gold set for a task schema: `molabel gold create <slug> --task-schema <task-schema-id> --json`
- Promote a queue's adjudicated and agreed records: `molabel gold promote <slug> --queue <queue-id> --json`
- Append the records the model got wrong: `molabel gold append <slug> --execution <execution-id> --json`
- Show a gold set's version, newest items and open conflicts: `molabel gold show <slug> --json`
- Export a gold set's lines: `molabel gold export <slug> --raw`
- Show quality dashboard: `molabel quality dashboard --json`
- Create an export: `molabel export create --file export.json --json`
- Create a release: `molabel release create --file release.json --json`
- Read a canonical artifact: `molabel artifact read <kind> <selector> --json`
- Diff a proposed change: `molabel artifact diff <kind> <selector> --candidate-file <path>`
- Write a canonical artifact safely: `molabel artifact write <kind> <selector> --content-file <path> --expected-hash <hash>`
